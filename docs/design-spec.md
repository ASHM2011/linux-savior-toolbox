# Linux萌新救星工具箱 v3.0 - UI设计说明文档

## 一、项目概述

**项目名称**：Linux萌新救星工具箱 (Linux Savior Toolbox)
**版本**：v0.1 Prototype (UI原型)
**技术栈**：Qt 6.5+ / C++17 / CMake
**目标用户**：完全不懂终端命令的Linux图形化界面新手

---

## 二、设计理念

### 2.1 核心设计原则

1. **萌新友好**：所有文本使用大白话，避免专业术语
2. **安全第一**：危险操作有明显的视觉警示和二次确认
3. **智能适配**：根据发行版和桌面环境自动显示/隐藏功能
4. **视觉一致**：统一的设计语言、配色方案、交互模式
5. **渐进式披露**：复杂功能分层展示，不一次性 overwhelm 用户

### 2.2 设计目标

- 让完全不懂Linux的小白也能轻松上手
- 把所有需要敲命令的操作变成"点一下按钮"
- 提供最严格的安全防护，防止误操作搞坏系统
- 美观、现代、符合原生桌面体验

## 三、参考UI借鉴点分析

### 3.1 借鉴的设计元素

从5张参考UI图中提取并借鉴的核心元素：

**布局结构**：
- ✅ 左侧垂直导航栏 + 右侧内容区的经典布局
- ✅ 顶部搜索栏，支持全局搜索
- ✅ 右上角系统信息徽章（发行版、桌面、内核、运行状态）

**视觉风格**：
- ✅ 卡片式设计，圆角边框，柔和阴影
- ✅ 蓝色主色调 (#3B82F6)，科技感强
- ✅ 浅灰背景 (#F8FAFC)，白色内容卡片
- ✅ 丰富的色彩语义：绿=成功/安全、红=危险、橙=警告、蓝=主要操作

**交互模式**：
- ✅ 标签页切换（如系统清理的多个分类）
- ✅ 快捷命令栏（终端页面顶部）
- ✅ 紧急修复专区的大卡片式入口
- ✅ 开关控件（设置页面）

### 3.2 创新改进之处

在参考UI基础上的创新和优化：

1. **命令元数据系统**：每条命令都有完整的萌新注释，点击❓图标可查看详细拆解
   - 逐参数解释命令每个部分的作用
   - 萌新常见坑点警示
   - 安全等级可视化标识

2. **渐进式安全防护**：
   - 绿色=完全安全、黄色=谨慎操作、红色=危险操作
   - 危险操作前二次确认，红色大字警示
   - 管理员权限按钮带盾牌图标标识

3. **终端与工具箱深度联动**：
   - 所有命令都有"后台执行"和"在终端中执行"双选项
   - 快捷命令栏一键执行常用操作
   - 执行结果高亮标注成功/失败

4. **批量任务系统**：
   - 预设3个核心批量任务（系统维护、深度清理、桌面修复）
   - 可视化展示任务流程和进度

5. **实时仪表盘**：
   - CPU、内存、磁盘实时使用率
   - 系统运行时间、发行版信息
   - 快捷操作入口（一键更新、清理缓存等）

- **圆角大小**：
  - 大卡片：12px
  - 按钮/输入框：8px
  - 徽章/标签：999px（药丸形）

- 主按钮：蓝色背景 + 白色文字 + 8px圆角

**输入框**：

## 五、功能模块设计（优先级1-4）

### 5.1 优先级1：安全与命令理解体系 ✅

**命令元数据系统**：
- 为每条命令建立完整元数据（ID、命令、权限、萌新名称、作用、参数拆解、安全等级、效果、坑点）
- 命令详情对话框：点击❓图标弹出，完整展示所有信息
- 安全等级徽章：✅完全安全 / ⚠️谨慎操作 / ❌危险操作

**权限白名单系统**：
- 全局权限映射表，明确标注每条命令的权限要求
- 绝对禁止管理员权限的命令：重启桌面、重启文件管理器、清理回收站、修改用户配置、重启输入法
- 权限可视化：需管理员权限的操作有明确标识

**危险操作防护**：
- 所有修改系统的操作执行前弹出二次确认
- 确认对话框用红色大字标注风险
- 首页紧急修复专区，最显眼位置展示

### 5.2 优先级2：终端模拟器 ✅

**终端界面**：
- 仿macOS终端风格的标题栏（红黄绿灯）
- 黑底白字，Fira Code等宽字体
- 支持命令输入和执行（演示模式）

**工具箱联动**：
- 快捷命令栏：更新系统、清理缓存、重启桌面、清理回收站
- 一键切换到终端并执行命令
- 执行结果高亮标注成功/失败
- 支持清空和导出日志

### 5.3 优先级3：一键执行功能 ✅

**执行可视化**：
- 进度条动画 + 实时状态提示（大白话）
- 成功/失败结果明确展示
- 实时输出显示

**批量任务系统**：
- 3个预设任务：一键系统维护、一键深度清理、一键桌面修复
- 彩色卡片式设计，每个任务有独立主题色
- 展示任务包含的步骤

### 5.4 优先级4：系统检测与智能适配 ✅

**系统信息检测**：
- 自动检测发行版（Ubuntu/Fedora/openSUSE/Debian）
- 自动检测桌面环境（GNOME/KDE/XFCE）
- 自动检测显卡类型（NVIDIA/AMD/Intel/VirtIO）
- 自动检测双系统
- 磁盘/内存使用情况检测

**智能适配**：
- 侧边导航自动过滤：非对应桌面的功能不显示
- 命令自动适配：不同发行版使用对应包管理器命令
- 系统信息徽章实时展示当前环境

## 八、技术实现要点

### 8.1 架构设计

- **模块化设计**：核心逻辑与UI分离，便于维护和扩展
- **信号槽机制**：所有模块间通信使用Qt信号槽，解耦彻底
- **单例模式**：系统检测器、命令执行器、权限管理器等使用单例
- **模拟执行**：原型阶段使用模拟执行，方便UI演示

### 8.2 关键技术点

1. **系统检测**：读取 `/etc/os-release`、环境变量、`lspci` 等
2. **样式表**：使用QSS实现完全自定义的UI样式，类似CSS
3. **资源系统**：Qt资源系统管理样式表等静态资源
4. **命令元数据**：QMap存储所有命令信息，支持按ID查询和分类搜索

### 8.3 编译运行

```bash
# 创建构建目录
mkdir build && cd build

# CMake配置
cmake ..

# 编译
make -j$(nproc)

# 运行
./LinuxSaviorToolbox
```

## 十、总结

本UI原型基于参考设计进行了创新性改进，在保持视觉美观的同时，重点强化了：

1. **萌新友好**：所有命令都有大白话解释和逐参数拆解
2. **安全防护**：三级安全等级 + 二次确认 + 权限白名单
3. **智能适配**：自动识别系统环境，只显示用户真正需要的功能
4. **交互一致性**：统一的设计语言和交互模式，降低学习成本

原型已可正常编译运行，包含优先级1-4的所有核心界面和交互逻辑，为后续功能开发奠定了坚实的基础。
